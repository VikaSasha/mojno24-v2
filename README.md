# Сайт ООО «Новые продукты»

Статический сайт на HTML, CSS и JavaScript без фреймворков и сборщиков. Его можно разместить на любом хостинге. Русская версия — 23 страницы, английская — 8 (папка `en/`).

## Как посмотреть локально

```
powershell -ExecutionPolicy Bypass -File tools\serve.ps1
```
Откройте http://localhost:8140/

## Структура

| Путь | Что внутри |
|------|-----------|
| `*.html`, `en/*.html` | Страницы. Шапка, меню, окно заявки и подвал вставляются сборкой |
| `partials/` | Общие блоки: `header`, `drawer` (мобильное меню), `request` (окно «Сотрудничество»), `footer` и их `-en` версии |
| `assets/css/main.css` | Дизайн-система (токены в `:root`) и общие стили |
| `assets/css/brand.css` | Страницы брендов в стиле листовок: Street Lunch (зелёная «рваная» бумага, горох, таймер, полароиды), РисоМишки (небо, лучи, медвежата, пейзаж), общий герой для остальных; анимации и их отключение при prefers-reduced-motion |
| `assets/js/data.js` | **Все данные**: продукты и форматы, сети и города, новости, соцпроекты, награды, FAQ, контакты, ссылки |
| `assets/js/app.js` | Поведение: каталог, карточка, бренды, карта, заявка (mailto), табы, меню, лайтбокс |
| `assets/fonts/` | Шрифты Google Fonts, размещены локально: Onest, Sofia Sans Extra Condensed; для страниц брендов — Rubik и Marck Script |
| `assets/img/` | Оптимизированные изображения (собраны скриптом из «! Маркетинг») |
| `assets/img/retail/` | Логотипы сетей для «Где купить» (источники — ниже) |
| `assets/img/docs/` | Сканы деклараций и сертификатов |
| `assets/video/`, `assets/img/video/` | Ролики (H.264) и их обложки |
| `assets/downloads/` | Медиакит: ZIP с фото продукции, SVG-знак |
| `tools/` | `build.ps1` (сборка блоков), `export-images.ps1` (фото), `pdf-thumbs.ps1` (превью писем и дипломов), `video-transcode.ps1` и `video-posters.ps1` (видео), `serve.ps1` |
| `docs/prompts.md` | Бриф на съёмку и промпты для генерации |

## Как обновлять

- **Ссылки на соцсети и маркетплейсы.** В `assets/js/data.js`, блок `CONFIG.socials` и `CONFIG.marketplaces`, впишите `url`. Пустая ссылка не показывается на сайте. Instagram выводится со сноской о Meta.
- **Продукты, составы, массы.** Тоже в `data.js`, массив `PRODUCTS`. Пометка `TBD("…")` выводится на сайте как жёлтая «уточнить: …». Замените её на значение.
- **Шапка или подвал.** Отредактируйте файл в `partials/`, затем выполните `powershell -ExecutionPolicy Bypass -File tools\build.ps1`.
- **Новые фото.** Добавьте строку в `tools/export-images.ps1` и запустите скрипт (подробности в `docs/prompts.md`).
- **Каталог.** Фильтров и переключателя видов нет: продукция показана группами, есть поиск. Ссылки на группу — `catalog.html#grp-<id>` (например, `#grp-street-lunch-doy`).
- **Стаканы Street Lunch.** Формат `cup` — классический крафтовый дизайн в продаже (фото `products/sl-*-cup-classic.jpg` из «! Маркетинг\! Стаканы\Supy»). Формат `cupnew` — новый цветной дизайн, в `FORMATS` у него `soon: true`, поэтому на карточках и странице товара выводится плашка «Скоро в продаже». Когда новый дизайн поступит в продажу, уберите `soon: true`.
- **Логотипы брендов.** Хрумстик — `assets/img/brand/hr-logo.png`, Наша Каша — `nk-logo.png` (поле `logo` у бренда в `data.js` выводит логотип вместо текстового заголовка на странице бренда).
- **Группы каталога.** Порядок и состав групп — массив `CATALOG_GROUPS` в `data.js`. У Street Lunch подгруппы по упаковке задаются полем `split`. Формат без позиций (сейчас «Мешок») показывается карточкой «уточнить», пока в `PRODUCTS` нет позиций с этим форматом.
- **Логотипы сетей.** Положите файл в `assets/img/retail/` и укажите `logo: "retail/имя"` у сети в массиве `RETAIL`. Белый логотип — добавьте `logoBg` с фирменным цветом подложки. Без `logo` выводится название текстом.
- **Видео.** Список роликов — массив `VIDEOS` в `data.js`; на странице нужен блок `data-videos="id1,id2"`.
- **Стена отзывов (главная, «Нас выбирают»).** Массив `REVIEWS.wall` в `data.js`: `bubble` — короткое сообщение, `card` — как карточка Ozon (`stars`, `pros` — достоинства, `cons` — недостатки, `text` — комментарий). Средних оценок на стене нет (по решению команды). Сейчас тексты — пересказ отзывов с оценкой 5★ без имён. Настоящий отзыв ставится с полями `verbatim: true` и `author` (первая буква имени — её покажет аватар); когда все отзывы настоящие, подпись «в пересказе» пропадает сама. Ссылки на магазин в блоке нет. Длинная стена сворачивается, кнопка «Показать все отзывы» раскрывает её. Раскладка — «кладка» (`initReviews`): каждый отзыв встаёт в самую короткую колонку, поэтому колонки заканчиваются почти вровень; на телефоне — одна колонка «как переписка».
- **«Для партнёров» — одна страница `business.html`.** Пять направлений по единому шаблону (`#retail`, `#stm`, `#horeca`, `#export`, `#suppliers`), затем «Как начать» (`#start`), документы и реквизиты (`#docs`), вопросы и общая заявка (`#form`). Липкое меню подсвечивает текущий раздел; кнопки направлений выбирают нужный пункт в форме. Старые страницы `retail.html`, `private-label.html`, `b2g.html`, `export.html`, `suppliers.html`, `documents.html` — переадресации на соответствующий якорь. Цены и условия для дистрибьюторов на сайте не показываем.
- **Представленность сетей.** `RETAIL[].stores` и `CITIES` в `data.js`: Перекрёсток — адресная программа X5 (306 магазинов, РисоМишки), Светофор — выгрузки УралРитейлГрупп, ЮгРитейлЛогистики, ПармаЛогистик (186 точек, Street Lunch). Остатки не учитываются. Логотипы на главной сортируются по числу магазинов.
- **Соцпроекты** устроены как новости: `social.html` — фильтр и карточки, `social.html?id=<id>` — страница проекта с письмами/фото. Данные — `PROJECTS` в `data.js`.
- **Фото полок** (`assets/img/shelves/`) — ценники размыты; оригиналы без размытия в сайт не кладём.
- **Карта поставок (главная, RU и EN).** Блок `data-export-map`, рисует `initExportMap` в `app.js`. Контуры стран — `assets/js/geo-export.js` (Natural Earth 1:50 млн, общественное достояние; проекция Ламберта, рамка от Калининграда до Владивостока). Города сетей берутся из `CITIES` в `data.js` (поле `en` — название для английской версии); страны экспорта и точка Владивостока (доставка маркетплейсами) заданы в `initExportMap`. Скрипт `geo-export.js` подключается только на главных.
- **Видео на страницах брендов.** Одна карусель на бренд: `carousel vcar` + `data-videos` на `.carousel__track`; горизонтальные и вертикальные ролики выравниваются по одной высоте (`--vh`).
- **Шапки новостей.** Поле `cover` у новости в `NEWS` рисует единую шапку по тематике: `expo` (выставка: название, год, даты, город, площадка, стенд), `award` (награда: результат, марка, диплом или знак), `launch` (новинка: продукт). Цвета — `COVER_THEMES`. Новость без `cover` показывает фото или типографскую обложку.
- **Лента «Истории с полок и праздников».** Статичная разметка в `index.html`: фото — кнопка `.story` с `data-lightbox`, видео — `<div class="story story--video" data-videos="id">`.
- **Карусели.** Обёртка `data-carousel`, внутри `.carousel__track` и кнопки `data-prev` / `data-next`; если всё помещается, стрелки скрываются. На главной так сделаны соцпроекты (`data-projects-strip`, все проекты из `PROJECTS`; обложка события — поле `cover`) и новости (`data-news-list` без лимита).
- **«100 лучших товаров России».** Массив `BEST100` в `data.js`, вывод — блок `data-best100`. Дипломы пересняты из «! Маркетинг\НАШИ НАГРАДЫ!!!\награды 2024\100 лучших товаров» (900 px); эмблема `assets/img/awards/100-best-emblem.png` вырезана с диплома «Новинка» (архив «Логотипы_2024.7z» в той же папке распаковать нечем — 7-Zip не установлен; если достанете оттуда оригинальный логотип, замените файл).

## Заявки

Формы не отправляют данные на сервер: открывается почта посетителя с готовым письмом на info@newprod.ru. Чтобы заявки приходили без почтовой программы, нужен обработчик форм на хостинге или сервис вроде Web3Forms. Тогда меняется одна функция — `composeMail`/`submit` в `app.js`.

## Перед запуском

- Проверить у юриста `privacy.html`, `consent.html` и `cookies.html`.
- Найти по сайту класс `tbd` и заполнить все пометки «уточнить».
- Карта «Где купить» использует OpenStreetMap и Leaflet (unpkg.com). Для российского сайта рекомендуем перейти на Яндекс Карты: нужен API-ключ.
- Если хостинг умеет WebP или AVIF, сконвертировать PNG-вырезки в `assets/img/cutouts/`: экономия около 70% веса.
