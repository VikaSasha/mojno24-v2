# Новые продукты — сайт, версия v2

Доработанная локальная версия сайта [mojno24.ru](https://mojno24.ru) (ООО «Новые продукты», Челябинск):
копия собранного сайта на Next.js плюс надстройка с новыми разделами и админкой.

## Как запустить

Нужен Windows с PowerShell (входит в систему).

1. Скачайте репозиторий (Code → Download ZIP) и распакуйте.
2. Двойной клик по `Открыть сайт.cmd` — откроется http://localhost:8124/
3. Админка — `Открыть админку.cmd` или http://localhost:8124/admin/

Окно сервера не закрывайте, пока работаете с сайтом.

## Что добавлено к исходному сайту

- **Где купить** (`/gde-kupit`) — карта представленности, торговые сети, маркетплейсы, фото с полок.
- **Поставщикам** (`/suppliers`), **Карта сайта** (`/karta-saita`), страница **404**.
- Вкладки на странице товара: характеристики, состав, пищевая ценность, логистические данные.
- Новые позиции каталога: Street Lunch и «По-Уральски» в коробках 240 г, «Наша Каша», РисоМишки во фруктовой глазури и солёные хлебцы.
- Фото готовых блюд, фотогалерея на главной, ссылки в меню и подвале.
- **Админка** (`/admin`): каталог, новости, «Где купить», загрузка фото.

## Устройство

| Путь | Что это |
|---|---|
| `index.html`, `_next/`, `catalog/`, `product/`, … | Копия собранного сайта (Next.js) |
| `v2/v2.js`, `v2/v2.css` | Надстройка: подключена ко всем страницам и добавляет новые блоки после загрузки страницы |
| `v2/data/catalog.json` | Товары, добавленные через админку |
| `v2/data/news.json` | Новости из админки |
| `v2/data/where.json` | Торговые сети и точки на карте для «Где купить» |
| `v2/templates/` | Шаблоны страниц новых товаров и новостей |
| `v2/img/` | Фото: упаковки, полки, готовые блюда, галерея |
| `admin/` | Админка |
| `serve.ps1` | Локальный сервер: раздаёт сайт и сохраняет данные из админки |

Сохранять изменения через админку можно только при запуске через `serve.ps1`:
сервер записывает JSON, делает резервную копию в `v2/data/backup/` (в репозиторий не попадает)
и создаёт страницы новых товаров и новостей.

Карта на странице «Где купить» использует Leaflet и подложку OpenStreetMap — нужен интернет.

## Ограничения

- Это надстройка над собранным сайтом, а не его исходный код: чтобы перенести доработки на mojno24.ru,
  их нужно встроить в исходники Next.js.
- В админке нет пароля — сервер принимает запросы только с этого компьютера.
- Товары и новости исходного сайта в админке не редактируются.
